# Estudos de Java

Exercícios de Java reunidos por tema. Cada atividade mantém sua própria pasta e documentação.

| Pasta | Conteúdo |
| --- | --- |
| [Fundamentos e estruturas de dados](java-parte-2/) | Vetores, métodos, objetos, listas estáticas e listas ligadas |
| [Programação orientada a objetos](java-poo/) | Herança, polimorfismo, abstração, interfaces, biblioteca e e-commerce |

```text
Java/
├── README.md
├── java-parte-2/
│   ├── README.md
│   └── exercícios de fundamentos e estruturas de dados
└── java-poo/
    ├── README.md
    └── exercícios de programação orientada a objetos
```

Abra uma atividade por vez no VS Code e siga o README do grupo. Algumas atividades reutilizam nomes de classes; compile somente a pasta do exercício escolhido.

Os projetos de APIs estão organizados separadamente em [Spring-Boot](../Spring-Boot/).
