# Java — Parte 2: fundamentos e estruturas de dados

Material organizado da segunda parte das aulas de Java. Cada pasta é uma atividade independente; algumas reutilizam nomes de classe como `Pessoa` e `Noh`, então compile uma pasta por vez.

## Sequência de estudo

| Pasta | Conteúdo | Conceitos |
| --- | --- | --- |
| 01-vetores-e-metodos | Descoberta de menor e maior valor | vetores, laços e retorno de método |
| 02-pessoa-e-vetores | Pessoa mais velha de um vetor | objetos e arrays de objetos |
| 03-lista-estatica | Lista baseada em array | capacidade, inserção e percurso |
| 04-lista-ligada | Inserção no início | nós e referências |
| 05-lista-ligada-clientes | Modelo de lista de clientes | modelagem e operações pendentes |
| 06-fundamentos | Métodos, Scanner, repetição e vetores | sintaxe básica de Java |

## Como executar

Entre na pasta desejada e use:

```powershell
javac *.java
java NomeDaClasseComMain
```

Por exemplo, em `01-vetores-e-metodos`, execute `java Exercicio1`.

## Observações

- Foram mantidos somente os arquivos `.java`; arquivos compilados (`.class`) e bibliotecas locais foram removidos.
- Alguns arquivos são esboços de exercícios e possuem métodos propositalmente incompletos. Eles servem como ponto de partida para praticar a implementação.
